# ja-space

日本語と英数字のあいだに半角スペースを入れていないかを検査します。スペースの見た目はレンダラーが決めるので、原文には入れません。

- 対象: Markdown、TypeScriptのコメント、プレーンテキスト、JSON
- 実行: `node scripts/lint/ja-space/cli.ts`（`--fix`で自動修正）
- 実装: [rule.ts](./rule.ts)、[cli.ts](./cli.ts)

## 経緯

- chrome-ext-templateから移植しました。
- 移植の際にTSXの対応を外しました。この雛形にはTSXがないためです。
- TypeScriptの文字列リテラルとテンプレートリテラルの中身は検査しないようにしました。pre-commitの`--fix`が、テストデータの`"会議 2024 メモ"`を書き換えてテストを壊したためです。文字列はデータであり、表記の規則を当てる対象ではありません。`${}`の中のコメントは検査します。
- 3つのカスタムlintで同じ処理が重複し、fallowの重複検出に掛かりました。ファイルの列挙、行と列の計算、一時ディレクトリを[shared](../shared/)にまとめました。
